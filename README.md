# financial-health-score-prediction
The Financial Health Score Generator is a Machine Learning and Deep Learning based project designed to analyze an individual's financial data and predict their financial health.
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Artificial Neural Network (ANN)
- FastAPI
## Key Features
- Financial data analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Financial health score prediction
- Machine Learning model comparison
- Personalized financial recommendations
- Real-time prediction using FastAPI
## Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Naive Bayes
- XGBoost
- Artificial Neural Network (ANN)
## Project Objective
To help users understand their financial health through data-driven predictions and personalized recommendations.
